# Projet POO – Version 1 (POO-v1)

## 🎯 Objectif
Modélisation d’un système de gestion de compatibilité entre adolescents dans un contexte d’échange. Cette première version couvre la base du modèle de données et les premiers critères de compatibilité.

## 📦 Contenu de cette version

- `Adolescent.java` : Classe représentant un adolescent (hôte ou invité) avec critères.
- `Critere.java` : Enumération des critères textuels (T) et booléens (B).
- `TestAdolescent.java` : Classe de test démontrant le fonctionnement des critères et de la compatibilité.
- `rapport_POO-v1.pdf` : Rapport de version avec UML, explication, et scénario de test.

## ✅ Fonctionnalités implémentées

- Ajout de critères textuels et booléens à un adolescent
- Vérification de compatibilité entre un hôte et un invité selon :
  - Allergie aux animaux vs. présence d’animaux
  - Régime alimentaire
- Structure extensible pour ajouter d’autres critères

## 🧪 Tests

- Scénario test dans `TestAdolescent.java`
- Affichage console des critères et du résultat de compatibilité (voir PDF)
